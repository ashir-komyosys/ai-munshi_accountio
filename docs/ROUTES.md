# Routes

- **Auth:** `/login`, `/register`, `/verify-otp`, `/forgot-password`
- **Onboarding:** `/onboarding`, `/onboarding/connect-whatsapp`, `/onboarding/business`, `/onboarding/create-book`
- **Core:** `/app/overview`, `/app/munshi`, `/app/munshi/history`
- **Books:** `/app/books`, `/app/books/new`, `/app/books/[bookId]`, `/app/books/[bookId]/settings`
- **Khatas:** `/app/khatas`, `/app/khatas/new`, `/app/khatas/[khataId]`, `/app/khatas/[khataId]/statement`
- **Transactions:** `/app/transactions`, `/app/transactions/new`, `/app/transactions/[transactionId]`, `/app/transactions/{sales,purchases,expenses,receipts,payments,transfers,returns,journals}`
- **Inventory:** `/app/inventory`, `/app/inventory/new`, `/app/inventory/[itemId]`, `/app/inventory/{categories,movements,adjustments}`
- **Cash & Finance:** `/app/cash-bank`, `/app/cash-bank/new`, `/app/cash-bank/[accountId]`, `/app/cash-bank/{transfers,loans,capital,assets,liabilities,salaries}`
- **Reports:** `/app/reports`, `/app/reports/{profit-loss,balance-sheet,cash-flow,trial-balance,general-ledger,day-book,sales,purchases,expenses,receivables,payables,inventory,aging}`
- **Documents:** `/app/documents`, `/app/documents/[documentId]`
- **Settings:** `/app/settings`, `/app/settings/{profile,business,whatsapp,language,appearance,notifications,users,security,subscription,billing,help}`
