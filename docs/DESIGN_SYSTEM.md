# Design System

- **Primary Brand:** `#EA5003`
- **App Background:** `#FCFAF7`
- **Warm Cream:** `#FFF8F3`
- **Card Surface:** `#FFFFFF` (Dark mode: `#18181B`)
- **Typography:** Plus Jakarta Sans (headings), Inter (body), Orbitron (brand accent), Noto Sans Arabic (Urdu RTL), `tabular-nums` + `bidi-isolate` for financial figures.
- **Asset Replacement:** Replace placeholder SVGs in `src/components/common/BrandAssets.tsx` with official `public/brand/` and `public/mascot/` assets when provided.
